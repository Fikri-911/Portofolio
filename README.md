# Portfolio Achievement

Template React + Vite untuk personal developer archive.

## Jalankan
```bash
npm install
npm run dev
```

## Bagian yang perlu diedit
- `src/data/profile.js` -> biodata dan link
- `src/data/achievements.js` -> achievement
- `src/data/documentation.js` -> dokumentasi/project
- `src/styles.css` -> warna, typography, layout
- `src/components/Hero.jsx` -> tampilan hero/foto

Catatan: gambar dokumentasi pada contoh menggunakan URL Unsplash sebagai placeholder. Ganti dengan gambar milik sendiri jika sudah tersedia.
